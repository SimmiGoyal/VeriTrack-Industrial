# 🛡️ VeriTrack: Multi-Modal AI Content Verification System

An industrial-grade, multi-modal tracking dashboard built to detect and analyze synthetic data across **Text, Audio, and Video** assets. This project serves as a security pipeline for corporate workflows to verify content authenticity against Deepfakes, Generative LLMs, and Voice Clones.

---

## 🚀 Key Features

- **Text Track:** Evaluates document perplexity and structural burstiness to catch synthetic outputs (GPT/Claude).
- **Audio Track:** Generates digital frequency prints (Mel-Spectrograms) to track artificial anomalies in cloned voices.
- **Video Track:** Frame-by-frame deconstruction using facial landmark meshes to detect deepfake spatial distortions.
- **Industrial Dashboard:** Wide-layout analytics center with adjustable detection sensitivity thresholds.

---

## 🛠️ Tech Stack & Frameworks

- **Interface:** Streamlit (Python-native Web App framework)
- **Computer Vision:** OpenCV, MediaPipe (Facial mesh tracking)
- **Deep Learning / NLP:** Ultralytics YOLOv8, Hugging Face Transformers
- **Audio Processing:** Librosa (Frequency wave analysis)
- **Database:** Local JSON structure *(Migration to Cloud Firebase planned)*
